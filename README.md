### Run it from this page

Use the orange button to discover eligible open-source repositories and request forks. Use the red **REFRESH GAME PORTS** button to independently refresh the PC game-port directory in the Arcade Orbit repository. The two workflows are separate so game-library refresh failures cannot break repository discovery.

1. Tap **OPEN WORKFLOW / RUN DISCOVERY**.
2. On GitHub Actions, tap **Run workflow**.
3. Choose the branch `main`.
4. Set `dry_run`:
   - `true` — preview candidate repositories only.
   - `false` — request actual forks for eligible candidates.
5. Tap **Run workflow** and review the logs and generated report.

**Configured safeguards:** minimum 100 stars, pushed within 180 days, licence and metadata checks, archived/disabled repository exclusions, duplicate checks, and a configured maximum of 10 fork requests per week. Actual forks depend on eligibility and GitHub permissions.

<details>
<summary><strong>Safety checklist before adding or running a project</strong></summary>

- Check the original repository and licence obligations.
- Read the README, security policy, release history, and open issues.
- Inspect install scripts, dependencies, workflows, and requested permissions.
- Never paste access tokens into code, issues, or this README.
- Do not run unknown code just because it passed metadata filters.

</details>
