<a href="https://github.com/NayumAhmed/NayumAhmed/actions"><img src="https://img.shields.io/badge/03%20%7C%20MISSION%20LOGS-VIEW%20RUN%20HISTORY-0E7490?style=for-the-badge&logo=github&logoColor=white" alt="View workflow runs"/></a>

**Two separate systems. Two separate missions.**

1. **Repository Discovery and Safe Forks** — scans for eligible open-source repositories and can request forks when you run it with `dry_run = false`.
2. **Refresh PC Game Port Library** — discovers game-port projects and updates the directory in Arcade Orbit. It updates project links; it does not automatically download or fork every game.

To launch a mission, open its workflow, tap **Run workflow**, review the options, and start it. Always inspect reports and project licences before using newly discovered code.
